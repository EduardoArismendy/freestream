# 🎥 FreeStream2

**FreeStream2** es una plataforma web que permite explorar películas y series disponibles de forma gratuita a través de distintos servicios de streaming. Está basada en [freestream2.netlify.app](https://freestream2.netlify.app) y pensada como un punto de partida para crecer con nuevas funciones, aportaciones y mejoras.

---

## 🔍 ¿Qué ofrece actualmente?

- Búsqueda y filtrado por título o género
- Muestra carátulas, sinopsis, calificación y plataforma donde está disponible
- Interfaz moderna y ligera, desarrollada en React/Vue (según tecnologías usadas)
- Totalmente desplegada en Netlify (servicio original como base)

---

## 🧠 Inspiración: la página original

🔗 **Demo en vivo:** [freestream2.netlify.app](https://freestream2.netlify.app)

El sitio original busca facilitar encontrar y ver contenido gratuito, con una interfaz minimalista y funcional. Usando esta base, **FreeStream2** agrega una mejor experiencia de usuario, optimizaciones de rendimiento y una estructura pensada para ampliar con nuevas características.

---

## 🚀 Tecnologías usadas

- React.js o Vue.js *(elige la que usaste)*
- Tailwind CSS o similar
- JavaScript moderno (ES6+)
- API pública de IMDb, TMDb, u otra fuente libre
